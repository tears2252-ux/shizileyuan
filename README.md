# 识字乐园 🎈

一款专为初阶小学生设计的识字启蒙 PWA 应用，认 → 读 → 写 → 练 四步学习法，让汉字学习像探险一样有趣！

## ✨ 功能特色

- **100 个核心汉字**，按 10 个生活主题关卡组织（数字、象形、自然、动物、家庭、活动、物品、校园、颜色、挑战）
- **四步学习法**：👀 认（拟物动画）→ 🗣️ 读（语音跟读）→ ✍️ 写（田字格描红+笔画动画）→ 🎯 练（大炮打靶游戏）
- **语音朗读**：内置中文 TTS，支持单字与组词发音
- **笔画动画**：基于 HanziWriter 的逐笔演示
- **游戏化激励**：星星收集、成就徽章、关卡解锁
- **PWA 离线可用**：支持安装到手机/桌面，离线也能学
- **进度自动保存**：本地存储学习进度，随时续学

## 🎮 游戏玩法

1. 从首页选择关卡（10 个主题目的地）
2. 每个汉字经过「认 → 读 → 写 → 练」四步
3. 写字用田字格手写板 + 笔画动画示范
4. 练习环节驾驶大炮击沉写着正确汉字的帆船
5. 收集星星和徽章，成为识字大王！

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- HanziWriter（笔画动画）
- Web Speech API（中文朗读）
- Service Worker + Manifest（PWA）

## 📂 项目结构

```
├── index.html          # 入口页面
├── manifest.json       # PWA 配置
├── sw.js               # Service Worker（离线缓存）
├── css/style.css       # 全部样式
├── js/
│   ├── app.js          # 应用入口与路由
│   ├── data.js         # 100 个汉字数据
│   ├── home.js         # 首页（关卡地图）
│   ├── learn.js        # 四步学习页
│   ├── practice.js     # 巩固练习页
│   ├── review.js       # 复习页（成就）
│   ├── storage.js      # 进度存储
│   └── tts.js          # 语音朗读
└── assets/             # 图标与启动图
```
